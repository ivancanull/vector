# Studies

This directory groups experiment-facing assets by study. It holds scripts,
reports, and figures. Raw run data stays in `experiments/`.

## Layout

- `online_bo/`: BO online and replay study notes.
- `online_lhs/`: LHS online study notes.
- `online_turbo/`: Turbo online study notes.
- `online_bnn/`: BNN online runner and notes.
- `online_owafs/`: OWAFS/LHSDB warmup runner, diagnostics, and reports.
- `online_comparison/`: Cross-method online comparison scripts and figures.
- `bnn_surrogate/`: Offline and few-shot BNN surrogate figures.
- `bnn_acquisition/`: BNN acquisition quality and EI replay figures.
- `uaw_afs/`: UAW/AFS reconstruction and sampling figures.
- `hfss_skill_playground/`: HFSS skill playground scripts and notes.

See `FIGURE_INDEX.md` for the old-to-new figure path map.
