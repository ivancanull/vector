submission material. Engineering implementation and operations docs live under
[../engineering/](../engineering/).

## Maintenance Rule

Keep claims tied to concrete artifacts in `experiments/`, notebooks, and
`studies/`. Put implementation-only runbooks and API contracts in
`docs/engineering/`.
